# Android App — Capacitor Wrapper Design

**Goal:** Package the existing Halfsies web app as an installable Android APK using Capacitor, with no code changes to the web app and no Play Store publishing requirement.

**Approach:** Capacitor in-place. Install Capacitor directly in the existing `C:\Dev\Halfsies` repo. Capacitor adds an `android/` folder at the repo root and a `capacitor.config.ts` config file. The web app builds to `dist/` as usual; `npx cap sync` copies those assets into the Android project.

---

## Project Structure

```
C:\Dev\Halfsies\
├── android/                        ← generated by Capacitor
│   └── app/src/main/assets/public/ ← synced from dist/
├── capacitor.config.ts             ← Capacitor config
├── src/                            ← unchanged
├── dist/                           ← built web assets
└── package.json                    ← gains @capacitor/* deps
```

## Configuration

`capacitor.config.ts` at the repo root:

```ts
import { CapacitorConfig } from '@capacitor/cli'

const config: CapacitorConfig = {
  appId: 'com.halfsies.app',
  appName: 'Halfsies',
  webDir: 'dist',
}

export default config
```

## Compatibility

No web app changes required. All existing features work in the Capacitor Android WebView:

| Feature | Status |
|---|---|
| Receipt parser, split calculator, Zustand store | Works — pure JS |
| `BrowserReceiptImagePreprocessor` (Canvas API) | Works — WebView supports Canvas |
| Tesseract.js (WebWorker + WASM) | Works — Capacitor serves assets via local HTTP, not `file://`, so WASM and workers load correctly |
| Camera capture (`<input capture="environment">`) | Works — Capacitor enables file access in WebView |
| Web Share API (`navigator.share()`) | Works — supported in Capacitor Android WebViews |
| Dark mode (`useThemeStore`) | Works — class-based theming, no native dependency |

**Smoke test:** After the first `cap sync`, verify Tesseract.js processes a receipt image end-to-end on the device. WASM loading is the one area that differs meaningfully from desktop Chrome.

## Build Flow

### First-time setup

Prerequisites: Android Studio (includes Android SDK and a bundled JDK 17+).

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init
npx cap add android
```

### Building an APK

```bash
npm run build       # build web assets to dist/
npx cap sync        # copy dist/ into android/ and update plugin configs
# Then in Android Studio: Build → Build Bundle(s)/APK(s) → Build APK(s)
```

The APK is output to `android/app/build/outputs/apk/debug/app-debug.apk`. Install on a device via USB (`adb install app-debug.apk`) or copy the file directly.

### Live reload (optional)

For iterating on UI without rebuilding the APK each time:

```bash
npx cap run android --livereload
```

Requires a physical device or emulator connected. Web changes appear instantly; native config changes still require a sync and rebuild.

## Out of Scope

- Google Play Store publishing
- Capacitor plugins beyond the default set
- iOS support
- Push notifications, deep links, or background tasks

## Future

A native Kotlin / Jetpack Compose version is planned in a separate repo. That version will use ML Kit for on-device OCR and provide a fully native Android UI. The Capacitor wrapper is the fast path to an installable APK while the native app is built.
